mdq

Query markdown tables from the command line. grep finds lines; awk chokes on markdown. mdq selects columns, filters rows and sorts — on any README or ledger.

cat README.md | mdq --select Package,Version --where License==MIT --sort Version --desc
mdq --file ledger.md --select Fecha,Ciclo --where Fecha==2026-11-05
